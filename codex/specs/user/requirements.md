# Device Data Monitoring System — User Requirements

## Access & Deployment
- Access the system over the customer intranet using a modern web browser without installing extra software.
- Sign in with the provided owner account on first use and immediately update the default password for security.

## User Management
- Owner can update their own credentials and create, edit, or deactivate additional administrator accounts.
- Administrators can invite read-only users who may view data and dashboards but cannot change configuration.

## Device Monitoring Experience
- View live readings from all connected monitoring devices with automatic refresh and smooth chart animations.
- See clear chart overlays that show current values, warning thresholds, and the gaps between them.
- Receive on-chart visual alerts (yellow for caution, red for critical) whenever a reading crosses its configured limits.

## Historical Insights & Reporting
- Select any device reading and time window to review historical trend charts.
- Export the displayed historical data set to downloadable CSV files for offline analysis.

## Device & Group Configuration
- Add new monitoring devices by specifying name, location, measurement units, sampling interval, and threshold rules.
- Edit or delete existing devices, keeping a consistent audit trail of configuration changes.
- Organize devices into groups; each group provides the same live and historical charting interfaces tailored to its members.

## Localization & Presentation
- Switch the interface language between English and Chinese at any time without losing context.
- Use a clean, attractive layout with responsive design and subtle dynamic effects that aid comprehension without distraction.

## Data Persistence
- Store all device configurations, user accounts, and collected readings on the server for reliable recovery after restarts.
